# Third-party software

ScanBridge downloads or bundles these. It ships none of FORScan's files.

| Software | How it is used | License |
|---|---|---|
| FORScan (Alexey Savin) | Downloaded by the user from forscan.org; license shown and accepted in the app | FORScan EULA |
| Wine (Gcenx macOS builds) | Downloaded at setup from github.com/Gcenx/macOS_Wine_builds | LGPL 2.1+ |
| innoextract | Bundled, unpacks the official FORScan installer on the user's Mac | zlib |
| Boost | Bundled with innoextract | Boost Software License 1.0 |
| xz / liblzma | Bundled with innoextract | 0BSD / public domain |
| zstd | Bundled with innoextract | BSD |
